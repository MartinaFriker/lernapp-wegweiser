# Lernapp-Wegweiser

Ein klickbarer Wegweiser für Lehrpersonen: Station für Station von der ersten Idee zur eigenen Lernapp.

0. Start: Vokabular & Niveau
1. Vorstellung / Rahmen
2. Wunsch / Spezifikation (inkl. Adressat:innen), mit Rückfragen-Schlaufe
3. Ethik-Check: Braucht's das? Pädagogischer Mehrwert
4. Umsetzungsplan inkl. Beratung, 4a Datenschutz-Check
5. Prototyp, (automatisiertes) Testing, Risiko abwägen
6. Testen
7. Feedback, zurück zu Station 2

Online: https://martinafriker.github.io/lernapp-wegweiser/

Eine einzige statische Datei (`index.html`), keine Datenerhebung. Häkchen und Eingaben bleiben im Browser der Nutzerin bzw. des Nutzers (localStorage).
